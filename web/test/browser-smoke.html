Browser smoke: API этапа 1 из настоящего браузера

Проверяет тот же путь, которым ходит интерфейс: текущий origin → (/api) → gateway → сервисы. Запускается вручную или автоматически: ?auto=1&email=admin@lms.local&password=Admin123!&write=1. Параметр then=app после успешных проверок сохраняет сессию и открывает каталог, чтобы можно было снять DOM уже отрендерившегося приложения (headless-проверка).
